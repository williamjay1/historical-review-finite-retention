## Source data

Raw ESA-ADB version 2 and SMD data are not redistributed. Their fixed sources
and licenses are:

- ESA-ADB version 2: https://doi.org/10.5281/zenodo.15237121, CC BY 3.0 IGO.
- SMD: https://github.com/NetManAIOps/OmniAnomaly, dataset MIT license,
  copyright 2021 NetManAIOps-SMD, fixed revision
  `7fb0e0acf89ea49908896bcc9f9e80fcfff6baf4`.

The repository contains derived high-score service records. These retain
selected original completed-window-last observations, but not full raw windows,
all observations, below-threshold histories or fitted model objects.
