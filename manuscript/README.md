# Manuscript files

- `ESWA_Manuscript.docx`: main manuscript, 16 pages.
- `ESWA_Supplementary.docx`: supplementary material, 7 pages.
- `ESWA_Manuscript.md`, `ESWA_Supplementary.md`: editable Markdown sources.
- `ESWA_Cover_Letter.pdf`: one-page cover letter.
- `ESWA_Cover_Letter.docx`: editable cover letter source.
- `latex_cas/ESWA_Manuscript_cas.tex`: same manuscript in the Elsevier CAS
  double-column LaTeX template (`cas-dc.cls` version 2.4). Build instructions
  are in `docs/LATEX_CAS_BUILD.md`.

The Word files contain native tables and OfficeMath equations. The final layout
was checked with a Microsoft Word PDF export. LibreOffice headless misreads the
fixed Word table grid in this file; use Word for the final layout.
